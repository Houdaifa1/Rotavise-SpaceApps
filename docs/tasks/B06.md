# B06 — Suggest mode proposes only crops with strong evidence

**Needs:** B02 · **Board:** [BOARD.md](BOARD.md) · **How:** [WORKFLOW.md](WORKFLOW.md)

## Problem

In suggest mode (the farmer names no crops) the top rotations use minor crops
whose rules are model recall (amaranth, rocket, berseem, chard), while sourced
staples rank far lower (durum wheat rank 46–178). Crops with fewer, weaker
rules pass more easily. See DECISIONS "Regional comparison policy" and
`docs/evidence/live/2026-11-12-b7/regional-summary.md`.

## Do

1. Design an evidence-strength rule for suggest mode with Houdaifa (for
   example: suggest only crops whose planting window, cycle and temperature
   rules are sourced or double-checked, and show the others as "not enough
   evidence to suggest"). Record it in DECISIONS.
2. Pin it as a new comparison policy; old pins and results stay identical.
3. Rerun the six-region evaluation (`pnpm test:regional-eval`) and compare.
