# B03 — Sharp Google satellite map, NASA/EOX as fallback

**Needs:** — · **Board:** [BOARD.md](BOARD.md) · **How:** [WORKFLOW.md](WORKFLOW.md)

## Why

The current base map (EOX Sentinel-2 cloudless, 10 m) is blurry at field zoom.
The Space Apps Global Offers allow participants to use the Google Maps API
(Google Cloud offer). Google's Map Tiles API satellite tiles are sharp at field
level.

## Rules from Google (checked 14 Nov 2026)

Map Tiles API policies:
https://developers.google.com/maps/documentation/tile/policies

- Show the Google Maps logo (16–19 px high, clear space, never covered) and the
  full `copyright` string from the viewport endpoint, updated as the view moves.
- Cache only as the HTTP cache headers allow; no pre-fetching, bulk download or
  offline storage.
- Map visualisation only: no image analysis of Google tiles.
- Session token from `POST https://tile.googleapis.com/v1/createSession`
  (`mapType: satellite`, `language`, `region`), valid about two weeks.
- Max zoom varies by place: read `maxZoomRects` from the viewport endpoint.

## Do

1. The key is `GOOGLE_MAP_TILES_KEY` in `.env` only (Houdaifa creates it,
   restricted to the Map Tiles API and the app's origins). Never commit it.
2. Create and renew the session on the server; give the browser only what it
   needs to load tiles.
3. Google satellite becomes the default base when the key is present;
   EOX/NASA imagery stays selectable and is used automatically when Google is
   unavailable.
4. Logo and copyright exactly as the rules say; update `THIRD_PARTY_NOTICES.md`
   and the About sources.
5. Measure: tiles sharp at zoom 17–19 over Tadla fields; pan and zoom smooth at
   390 px (phone) and 1440 px.
