# B05 — ESA WorldCover cropland check for fields

**Needs:** B02 · **Board:** [BOARD.md](BOARD.md) · **How:** [WORKFLOW.md](WORKFLOW.md)

## Why

Field suggestions and hand-drawn fields can land on towns, rock or water. ESA
WorldCover 10 m (2021, via Planetary Computer collection `esa-worldcover`)
marks cropland.

## Do

1. For a field outline, compute the share of cropland (WorldCover class 40)
   and of other classes, with the map's year and version.
2. Return it with the field (contract + OpenAPI) and use it to rank or filter
   field suggestions.
3. Never block a farmer: it is a warning, not a rule (fields change since 2021).
4. Licence (CC BY 4.0) in `THIRD_PARTY_NOTICES.md` and `docs/REFERENCES.md`.

## May change

A new server module, contracts, tests, docs. Not `apps/web` (that is F13).

## Checks

`pnpm lint`, `pnpm typecheck`, `pnpm test:unit`, `pnpm test:integration`.

## Done when

A field on farmland reports mostly cropland, a field drawn on a town reports
little, and all checks pass.
