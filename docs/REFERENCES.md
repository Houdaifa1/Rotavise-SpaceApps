# References, data sources and licences

This file lists every data set, model, standard and document that Rotavise uses
or cites, with how it is used and its reuse terms. The NASA Space Apps terms
require every source to be cited, even open ones. Software packages are in
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

How to read the **Check** column: **saved** means the provider's own metadata
or terms page was saved or read in this project (the file is named); **recheck**
means the entry is from the project's documents or from memory and its DOI,
year or licence must be re-checked on the provider page before submission. No
entry was invented, but "recheck" entries have not been confirmed against the
live page on the date below.

Last updated: 2026-11-08.

## 1. NASA Earth observations used by the tool

NASA Earth science data are distributed under NASA's open data policy
(full and open access, no exclusive rights). Give attribution to the data
producer as below. The tool never presents satellite values as measurements on
the field itself; each result states the grid size and the source.

## 5. Artificial intelligence (SI) used to build the project

The Space Apps terms ask teams to say how SI tools were used. See the README
section "How AI was used" for the plain statement. In short: the code, tests
and documents were written with Claude (Anthropic) and Codex (OpenAI) coding
agents under the owner's direction, and about 80 % of the rules in catalog
0.10.0 come from model recall, each labelled with its provenance and
confidence.
